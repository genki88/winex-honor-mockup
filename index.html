觸控區

四顆按鈕各約 150×112px，字級 20px、圖示 42px。以 45–60 歲的手指與老花設定，不是以設計稿好看設定。

一次點擊

點下去就寫入並切到 B 畫面，沒有確認對話框、沒有送出鈕。開啟到結束一次點擊，這是「十秒內」唯一能達成的做法。

可覆寫

當天再進來直接顯示 B，按「改成別的天氣」回到 A。同一天只會有一筆，不會累積成兩筆。

隱私聲明

固定在分頁底部、不隨捲動消失。文案就是規格裡那一句，不改寫、不縮短。

圖上的缺口

填答未達 3 人的那一天，資料庫整列不回傳。所以畫成斜線缺口，不能畫成 0 —— 畫成 0 會被讀成「那天沒人上班」。

店長看不到人

C 畫面沒有名字、頭像、單筆紀錄，也沒有可往下鑽的入口。這不是靠前端不畫，是資料庫那層就沒有這條路。
